# Earth texture

`solar-system-scope-earth-8k.jpg` is the unmodified **8K Earth Day Map** from Solar System Scope's free planetary texture library.

- Source page: https://www.solarsystemscope.com/textures/
- Direct source: https://www.solarsystemscope.com/textures/download/8k_earth_daymap.jpg
